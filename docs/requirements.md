# 기능 요구사항

## MVP
1. 이메일 기반 회원가입·로그인
2. 월간 대시보드: 예상 고정비 합계, 카테고리 비중, 확인할 일
3. 고정비 등록·수정·삭제: 이름, 금액, 주기, 결제일, 카테고리, 자동결제 여부
4. 계약 일정 관리: 시작일, 만료일, 메모
5. 구독 목록과 월 합계
6. 월별 고정비 비교 리포트

## MVP 제외
- 은행·카드 자동 연동
- 모바일 앱과 푸시 알림
- 결제 기능
- AI 추천

## 품질 기준
- 금액은 원 단위 정수로 저장
- 사용자는 자신의 데이터만 접근
- 데스크톱 화면(최소 1280px)에서 정보 밀도와 가독성을 우선
